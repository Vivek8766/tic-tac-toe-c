# Tic Tac Toe Game in C

## 📌 Description

Tic Tac Toe is a classic two-player game developed using the C programming language. Players take turns marking spaces on a 3×3 grid with their respective symbols, **X** and **O**. The objective is to get three symbols in a row, column, or diagonal to win the game.

## ✨ Features

* Two-player gameplay
* 3×3 game board
* Alternating turns between players
* Win detection for rows, columns, and diagonals
* Draw detection when all positions are filled
* Simple and user-friendly interface

## 🛠️ Technologies Used

* C Programming Language
* GCC Compiler
* VS Code (for development)

## ▶️ How to Compile and Run

### Step 1: Compile the program

Open the terminal in your project directory and execute:

```bash
gcc tic_tac_toe.c -o tic_tac_toe
```

### Step 2: Run the program

On Linux or Ubuntu:

```bash
./tic_tac_toe
```

On Windows:

```bash
tic_tac_toe.exe
```

**Note:** Replace `tic_tac_toe.c` with your actual C source filename if it is different.

## 🎮 How to Play

1. Start the program.
2. Two players take turns choosing positions on the board.
3. Player 1 uses **X**, and Player 2 uses **O**.
4. Enter a valid position when prompted.
5. The first player to align three symbols horizontally, vertically, or diagonally wins.
6. If all positions are filled and neither player wins, the game ends in a draw.
